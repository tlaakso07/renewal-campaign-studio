# ADR 001 — Persistent local prototype

2026-09-15. React + TypeScript + Vite client, Express TypeScript API, Node 24 built-in SQLite (WAL, foreign keys, migrations), private filesystem objects, separate durable SQLite job worker. Sharp composites deterministic SVG and source images; font outlines preserve exact text. FFmpeg/ffprobe assemble H.264/yuv420p/AAC MP4s. ZIP includes original rendered outputs, exact copy and immutable version manifests. Package-lock pins resolved library versions.

The local app binds 127.0.0.1:8787 (gallery remains 8766). Vite serves app/ and its required dependency modules, never the project root or originals. API and media are authenticated; tenant identity is derived from database sessions/memberships. API mutations require the explicit request-protection header; a supplied Origin must also be allowlisted. Access is checked again in workers. Local development identities are explicit opt-in, loopback-only and forbidden in staging/production. Production startup is deliberately blocked until deployment identity and policy configuration are implemented. No assumed permanent access to this assistant's credentials/tools.

Offers, brand rules and creative documents are immutable versions; updates require expected revision. JSON documents carry stable layer/scene IDs, exact asset dependencies, and offer/brand versions. SQLite transactionally reserves render units with idempotent jobs. One local worker with durable per-scene cache handles restart, cancellation and retries; external services stay disabled until endpoint, capability, access and identity are verified. Local render units are not a claim about provider dollars.

Private blobs are content addressed per company, with checksum, provenance and technical metadata. Imported font originals stay private; no web embedding until licensing is recorded. Unsupported vectors/layered sources retain originals; PDF-compatible Illustrator originals can receive separate raster previews through pdftoppm. Full intake is resumable by source ID. Downloads do not require manager approval.

Report import uses source account/date/ad/currency/timezone/attribution identity and replacement upserts; no sample metrics seed. Shared publications are explicit copied derivatives, not private file URLs. Conversations and preferences belong to the user within a company.

Official references checked: https://vite.dev/guide/ ; https://nodejs.org/api/sqlite.html ; https://sharp.pixelplumbing.com/api-composite/ ; https://ffmpeg.org/ffmpeg-filters.html . These establish tools, not provider integrations. Prototype output sizes are not placement certification. SQLite/private disk are deliberate local choices; multi-host deployment requires managed relational/object storage and durable distributed leases.
